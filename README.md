🌾 AgriYield – Intelligent Crop Yield Prediction & Forecasting

An end-to-end AI application that predicts crop yield using Machine Learning (CatBoost) and forecasts future production trends using advanced Time-Series models (Prophet).
Designed for students, researchers, and agricultural planners.

🚀 Project Overview

AgriYield helps users make smarter agricultural decisions by combining:
✔ Machine Learning
✔ Time-Series Forecasting
✔ Interactive UI
✔ Clean, modern frontend with React + Tailwind

The system takes environmental parameters as input and provides:

Crop yield prediction (t/ha) using CatBoost Regression

Multi-day yield forecasting using Prophet

Line chart visualization for predicted trends

🧠 Key Features
🔍 1. Crop Yield Prediction (CatBoost)

Predicts yield (in t/ha) based on soil nutrients and environmental factors

Automatic handling of categorical and numerical features

High-performance gradient boosting model

📈 2. Yield Forecasting (Prophet)

Forecasts upcoming yield for selected date ranges

Provides trend visualization and daily values

Handles seasonality, trends, and irregular patterns

🎨 3. Modern UI (React + Tailwind)

Responsive layout

Professional dashboard-style interface

Line graph visualization using Chart.js

Improved prediction summary cards

🔗 4. Full-Stack Integration

Frontend → Backend → Model → Forecast → Charts
All flows automated using Axios and FastAPI endpoints.
